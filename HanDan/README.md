# 菡萏咖啡．台股損益存摺

個人台股投資組合記帳工具。把每週手動記帳的 Excel，變成一本隨時可以打開、自動算損益績效的電子存摺。

這份文件是寫給**使用者**看的（要打開來記帳、查績效的人），不是給工程師看的程式說明。

---

## 1. 怎麼開始使用

資料夾裡找到 **`菡萏咖啡存摺.exe`**，直接雙擊。

- 會自動開一個小視窗（黑底文字），接著自動跳出瀏覽器連到記帳頁面。
- **那個黑底小視窗不要關掉**，它是背後在跑的小型伺服器，網頁的功能都要靠它。要結束使用時，直接把那個黑視窗叉掉（或按視窗裡的 Ctrl+C）就會一併關閉網頁功能。
- 如果沒看到黑視窗（例如用的是 `開啟存摺.bat` 而不是 `.exe`），效果一樣，只是那台電腦需要事先裝好 Python 環境。一般情況雙擊 `.exe` 最簡單。

### 第一次執行可能會看到的警告

Windows 可能跳出「**Windows 已保護您的電腦**」的藍色警告視窗（SmartScreen）。這是因為這個 `.exe` 沒有花錢申請程式簽章，不是中毒或壞掉。點左下角「**其他資訊**」，再點「**仍要執行**」即可，之後同一台電腦通常不會再跳。

如果防毒軟體另外跳出警示，也是類似原因（未簽章的獨立執行檔），可以放行。

也可能跳出「**Windows 防火牆已封鎖此應用程式的部分功能**」的視窗，這是因為程式要開一個網路連接埠（僅供這台電腦自己的瀏覽器連線，不會對外部網路開放）。勾選「私人網路」允許即可，公用網路不用勾也沒關係。

## 2. 資料夾裡的檔案，缺一不可

`菡萏咖啡存摺.exe` 必須跟以下幾個檔案放在**同一個資料夾**裡，才能正常運作：

| 檔案 | 用途 |
|---|---|
| `菡萏咖啡存摺.exe` | 雙擊啟動用 |
| `菡萏咖啡-台股損益存摺.html` | 記帳頁面本體 |
| `菡萏咖啡.xlsx` | 原始 Excel 損益表，現價／帳戶餘額／每週記帳的資料來源 |
| `菡萏咖啡_手操版.xlsx` | 備援用的 Excel（沒有也能跑，但建議留著，見下方說明） |

**不要把 `.exe` 單獨複製到別的資料夾使用**，它會因為找不到旁邊的 `.xlsx`／`.html` 而無法正常顯示資料。要換電腦用，請把整個資料夾一起複製過去。

## 3. 兩個帳戶

頁面上可以切換「**我的戶頭**」與「**可橙戶頭**」兩個帳戶，各自獨立記帳、獨立算損益，切換方式是點頁面上的帳戶切換鈕（在「01 總覽與趨勢」「02 持股明細」「03 存股與配息」都看得到）。

---

## 4. ⚠️ 資料存在哪裡——這是最容易踩到的地方

網頁上手動輸入或修改的東西（持股數量調整、配息紀錄、帳戶餘額、04 記一筆的交易紀錄……）**不是存進 Excel 檔案**，而是存在瀏覽器裡（類似瀏覽器的「記住這個網站的資料」）。

這代表：

- **同一台電腦、同一個瀏覽器**下次打開會記得你之前的修改。
- **換一台電腦、換一個瀏覽器（例如平常用 Chrome，改用 Edge 打開）、或是清除瀏覽器資料**，之前手動輸入的東西會**看不到**（不是被刪除，是換了個地方存，兩邊互不相通）。
- 頁面最上方如果出現「**目前狀態：無法自動儲存**」的紅色提示，代表這次連瀏覽器都存不進去（例如用無痕模式開啟），資料只在這次瀏覽期間有效，關閉分頁就消失。

**因此請養成習慣**：到「05 備份與還原」分頁，定期點「匯出備份」，存一份 JSON 備份檔在自己看得到的地方（例如自己的文件夾、雲端硬碟）。真的發生資料不見的狀況，也能用「匯入備份」把資料還原回來。

## 5. 現價、帳戶餘額是怎麼更新的

- **打開網頁時**：會自動從 `菡萏咖啡.xlsx` 讀取現價、帳戶餘額、未入帳配息、每週記帳，顯示在頁面上。這一步不會連網路，也不會改動 Excel 檔案，單純讀取。
- **按「取得盤後收盤價」按鈕**（在「02 持股明細」分頁）：才會真的連上證交所／櫃買中心抓最新收盤價，並把結果**寫回** `菡萏咖啡.xlsx` 的「現價」欄位，下次打開網頁就會看到更新後的價格。
  - 收盤前（13:30 前）按，抓到的是前一個交易日的收盤價；收盤後按，抓當天的。
  - 這個按鈕需要**能連上網路**才會抓到最新資料，連不上會顯示錯誤訊息，但不影響頁面其他功能照常使用。

**如果要按這個按鈕更新收盤價，請先關閉 Excel（不要讓 `菡萏咖啡.xlsx` 開著）**，否則 Excel 會鎖住檔案，寫入會失敗（頁面上會顯示「目前在其他程式中開啟」的錯誤訊息）。

## 6. 「04 記一筆」怎麼用

用來記錄每一筆股票的買進／賣出交易：

1. 選帳戶、年度、記帳日期、輸入商品名稱
2. 選「買進」或「賣出」，填平均成本與成交股數，價金會自動算好
3. 按「加入存摺」存進紀錄

下方「本週買賣總覽」會**自動把同一週（星期一到星期日）的交易加總**，算出本週買進、本週賣出、投資明細（賣出金額為正、買進金額為負，代表這週資金淨流入或流出）。

投資明細右邊有個「**匯入**」按鈕，按下去會把那一週的投資明細金額加進「帳戶餘額」。

**注意**：這一週還沒過完就先按「匯入」，之後「可用現金」欄位可能會把這週的交易重複算一次（因為「可用現金 = 帳戶餘額 + 當週投資明細」，這週的交易同時被算進帳戶餘額，也還在「當週」範圍內）。建議**等這一週過完、確定不會再新增交易了，再按「匯入」**比較保險。

## 7. 在 iPhone 上使用（電腦不開機也能用）

手機版是一個固定網址的網頁，開啟後就能查看總覽、持股與配息。電腦不用開機，人在外面用行動網路也看得到。

```
https://handan-web.vercel.app
```

**資料只有你看得到。** 網址本身任何人都能打開，但沒有登入就只會看到一個登入畫面，頁面裡不含任何數字。你的損益、持股、代號對照全部存在雲端，要用你的 Google 帳號登入才會下載下來。

### 第一次設定（只要做一次）

1. iPhone 開 **Safari**，輸入上面的網址。
2. 點「**使用 Google 登入**」，選你的帳號。
3. 資料載入後，點畫面下方中央的分享圖示（向上箭頭的方框）。
4. 往下捲找到「**加入主畫面**」，按右上角「加入」。

做完之後主畫面會多一個圖示，以後直接點它就能開啟，不必再輸入網址，登入狀態也會記住。

### 手機上的資料怎麼更新

**不用做任何事。** 你在電腦上的每一次操作，都會自動同步到雲端：

1. 點 `開啟存摺.bat`
2. 在網頁上編輯、按「**取得盤後收盤價**」
3. 手機隨時打開，就是最新的

第 2 步一存檔，電腦就會把最新狀態推上雲端，手機下次開啟時自動抓到。中間不需要跑批次檔，也不需要找 Claude。

電腦關機後，手機看到的是最後一次同步的內容。收盤前（13:30 前）按「取得盤後收盤價」拿到的是前一個交易日的價格，收盤後按才是當天的。

### 手機上有哪些功能不能用

手機版是**唯讀**的，這些操作會被擋下並顯示提示，**這是正常的，不是壞掉**：

- 「取得盤後收盤價」按鈕沒有作用，價格由電腦端同步過來。
- 配息的寫回、修改等會動到 Excel 的操作都不能用。

會動到 Excel 的功能一律只能在電腦上做，這是刻意的設計，避免手機誤觸改壞帳本。

### ⚠️ 手機上的手動編輯不會傳回電腦

同步是**單向的**：電腦到手機。你在手機上改的東西不會回到電腦，而且下次電腦同步新資料時會被覆蓋掉。

請**把電腦當唯一的記帳裝置，手機只用來查看**。

### 出問題時先看這裡

**登入後顯示「雲端尚無資料」**
電腦端還沒同步過。開一次 `開啟存摺.bat`，等黑視窗出現「雲端同步已更新」再重新整理手機。

**手機上的數字比電腦舊**
電腦端最後一次同步之後又改過東西。回電腦開一次存摺即可，開啟時就會同步一次。

**顯示「這個帳號沒有存取權」**
登入到別的 Google 帳號了。點「換一個帳號登入」重選。

## 8. 常見問題

**Q：雙擊 `.exe` 沒反應，或跳出黑視窗又馬上關掉？**
A：多半是 8765 這個網路連接埠已經被佔用（例如已經開過一次程式還沒關掉舊的視窗）。先確認沒有其他黑視窗還開著，全部關掉後再試一次。

**Q：網頁打開但現價/餘額都是空的或「尚未設定」？**
A：確認 `菡萏咖啡.xlsx` 真的跟 `.exe` 放在同一個資料夾。如果 Excel 檔案剛好被 Excel 打開著，讀取可能會受影響，請先關閉 Excel 再重新整理網頁。

**Q：按「取得盤後收盤價」出現「無法寫入」的錯誤？**
A：`菡萏咖啡.xlsx` 目前開在 Excel 裡，先把 Excel 關掉再按一次。

**Q：換了電腦，之前記的資料都不見了？**
A：見上方第 4 點——手動輸入的資料是存在瀏覽器裡，不會跟著檔案走。請用「05 備份與還原」匯出的 JSON 備份檔，在新電腦上用「匯入備份」還原。

**Q：改了 Excel 裡的資料，網頁沒有更新？**
A：重新整理網頁（F5）即可重新讀取一次 `菡萏咖啡.xlsx` 最新內容。
